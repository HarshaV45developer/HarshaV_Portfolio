# SILVERBOT — 3D Developer Portfolio

A modern, immersive 3D developer portfolio featuring an interactive silver robot, cinematic animations, and a clean futuristic interface.

## About the Project

SilverBot is a personal developer portfolio designed to showcase my professional background, technical skills, projects, and experience through an engaging 3D web experience.

## Features

- Interactive 3D robot experience
- Scroll-based animations and transitions
- Modern, responsive user interface
- Futuristic silver and white visual design
- Developer introduction and skills showcase
- Projects and professional experience sections
- Contact and social profile links

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Three.js / React Three Fiber (if used in the project)
- Git and GitHub

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/HarshaV45developer/HarshaV_Portfolio.git
```

Navigate to the project directory:

```bash
cd HarshaV_Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal to view the portfolio.
